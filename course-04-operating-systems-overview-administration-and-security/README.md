# Course 4: Operating Systems: Overview, Administration, and Security

## Course Summary

This course introduced me to operating systems, system administration, and the security features used to manage and protect Windows, Linux, and macOS environments.

I learned about the development and main features of operating systems such as Microsoft Windows, Linux, and macOS, including how operating systems manage hardware, software, files, storage, users, applications, and system resources.

The course covered Windows operating systems and Windows Server, including Windows editions, security features, file systems, user and group management, Active Directory, domain administration, remote services, Windows command-line tools, and system-management utilities. I also learned about Windows file systems such as FAT, FAT32, NTFS, and ReFS and how file permissions, encryption, access control, and storage management are used to protect information.

I studied Windows security and administration tools including Microsoft Defender Antivirus, Windows Security, Windows Defender Firewall, BitLocker, Encrypting File System (EFS), User Account Control, Local Security Authority, security auditing, event logs, patching, updates, and Kerberos authentication.

I also learned about Linux operating systems, the Linux kernel, distributions, the command-line interface, the Linux file-system structure, and the use of terminal commands for navigating directories, working with files, managing users, checking system information, installing software, and maintaining a Linux system. I practised commands for creating, copying, moving, viewing, and removing files and directories and learned how Linux system updates are managed.

The course also introduced macOS administration and security features, including Finder, Spotlight, Mission Control, Keychain, FileVault, privacy and security settings, accessibility settings, Time Machine, networking settings, and terminal access.

Finally, I learned the fundamentals of virtualization, hypervisors, virtual machines, cloud computing, cloud service models, cloud deployment models, and containerization. I studied concepts including IaaS, PaaS, SaaS, public, private and hybrid clouds, and container technologies such as Docker.

## Practical Learning

During the course, I completed hands-on activities involving both Windows and Linux system administration.

In Windows, I worked with user accounts, system information, file management, performance monitoring, Windows Defender, firewall settings, and other administrative tools.

In Linux, I used the terminal to navigate the file system, create and manage files and directories, work with user accounts, run system commands, and perform system maintenance and updates.

These exercises helped me become more comfortable working with operating systems from both graphical and command-line environments.

## Final Project

The final project placed me in the role of a junior cybersecurity analyst at a fictional company, Cyber Secure Inc. I was assigned **six system-administration and security tickets**, divided between Windows and Linux environments.

### Part 1: Windows Tasks

Using a Microsoft Windows Server lab environment, I was required to complete three Windows administration and security tasks:

* Create a new user account and a new group using Windows Server Manager, then add the user to the group.
* Check Windows virus and threat protection for updates and run a Quick Scan using Windows Security.
* Configure Windows Defender Firewall by creating an inbound TCP rule for port 80, allowing the connection across Domain, Private, and Public network profiles.

I was also required to capture screenshots showing the completed tasks as evidence of my work.

### Part 2: Linux Tasks

Using the Skills Network Cloud IDE and Linux terminal, I completed the remaining three tickets:

* Create a new Linux user with a secure password and verify that the account was successfully created.
* Create and manage directories and files, including Accounting and Payroll folders and a Best Practices file.
* Check for Linux system updates, install available updates, and review the package-management log to confirm recent changes.

Screenshots of the completed Linux tasks were also required as evidence of the work performed.

I successfully completed the final project with a score of **90%**.

The final project allowed me to apply Windows and Linux administration skills to practical cybersecurity-related tasks involving account management, endpoint protection, firewall configuration, file and directory management, and operating-system maintenance.
