# Course 2: Introduction to Cybersecurity Essentials

## Course Summary

This course introduced me to the fundamental principles of cybersecurity, including the confidentiality, integrity and availability triad, information protection, common cyber threats, malware, social engineering, authentication, access control, password security, encryption, device hardening, firewalls, VPNs and safe browsing practices.

I also studied password policies, hashing, brute-force attacks, dictionary attacks, rainbow-table attacks, single-factor authentication, two-factor authentication, multifactor authentication, single sign-on, role-based access control, least privilege, audit logging, non-repudiation, BIOS, UEFI, Secure Boot, Trusted Platform Modules, symmetric and asymmetric encryption, public-key infrastructure, digital certificates, browser cookies, SSL certificates, public Wi-Fi risks and the risks associated with rooted or jailbroken devices.

## Practical Learning

The course included practical Windows-based activities involving password-strength checking, Windows Local Group Policy Editor, password-policy configuration and Windows Firewall with Advanced Security.

## Final Project

For the final project, I worked in a Windows Server-based laboratory environment and resolved three service tickets across six tasks.

I:

1. Uninstalled the most recent Windows security update.
2. Temporarily paused automatic Windows updates.
3. Cleared Chrome browsing history, cookies, site data, cached images and files without deleting saved passwords or sign-in information.
4. Enabled Windows Defender Firewall.
5. Allowed Google Chrome to communicate through Windows Defender Firewall.
6. Blocked Firefox from communicating through Windows Defender Firewall.

This project helped me apply Windows update management, browser-data handling and firewall configuration in practical service-desk scenarios.
